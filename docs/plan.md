# ContextVocab 产品计划（Plan）

## 1. 项目定位
- 产品名称：ContextVocab
- 核心价值：在真实语境中完成“看懂单词 -> 记住单词 -> 持续复习”
- 当前阶段：MVP+（已具备阅读、点词卡片、练习、复习、词库、真题导入）

## 2. 核心问题与目标
- 问题1：背词脱离语境，记忆迁移差
- 问题2：AI 解释不稳定，结果质量波动
- 问题3：学习流程不闭环，复习不精准

- 目标A（学习效果）：提升“有效理解 + 次日复习”完成率
- 目标B（产品稳定）：降低 fallback 比例与错误率
- 目标C（内容扩展）：让真题导入可持续运营

## 3. 目标用户
- 备考用户：六级/考研/雅思阅读备考人群
- 使用场景：碎片化阅读学习、睡前复习、真题专项训练
- 用户任务：快速理解生词、沉淀个人词库、按系统节奏复习

## 4. 北极星指标与指标树
- 北极星指标：`次日复习完成率（D1 Review Completion）`

- 学习成效指标：
- 单篇平均加入词库数
- 练习正确率
- 复习“我会”比例（随天数上升）

- 体验效率指标：
- 点词后 3 秒内出卡率
- 卡片最终成功率（含自动恢复）
- 词库加入按钮点击成功率

- 稳定性指标：
- fallback 比例
- API 错误恢复率
- PDF 导入成功率

- 质量指标：
- 中文有效释义率
- 错义率（抽样人工评估）
- 新导入套题段落完整率

## 5. 90 天路线图
## 阶段 1（第 1-2 周）：打稳主链路
- 修复高频阻塞：入词库成功反馈、中文释义稳定性、导入错误提示
- 建立最小指标面板：3s 率、fallback 率、复习完成率
- 里程碑：主流程可稳定跑通并可观测

## 阶段 2（第 3-6 周）：提升学习质量
- 上线“语义质量路由”阈值配置（可调）
- 短语优先与功能词过滤策略优化
- 复习策略迭代（错词优先、近因优先）
- 里程碑：学习与质量指标同步上升

## 阶段 3（第 7-10 周）：内容规模化
- PDF 自动导入 + 人工校对 SOP 完整化
- 导入质量报告（段落完整率、异常率、可学习篇数）
- 里程碑：新增一套题只需数据操作

## 阶段 4（第 11-12 周）：简历与面试资产沉淀
- 输出 1 份产品复盘（问题-方案-指标变化）
- 输出 1 份实验报告（A/B 或前后对比）
- 输出 1 份稳定性报告（错误恢复与可用性）

## 6. 优先级规则（RICE简化）
- 必做 P0：影响主流程成功率/数据准确性的项
- 应做 P1：显著提升学习效果或复习命中率
- 可做 P2：体验增强但不影响闭环的项

## 7. 风险与应对
- 模型波动：多层路由 + 自动恢复 + 兜底卡片
- 内容脏数据：自动清洗 + 校对兜底 + 质量报告
- 指标失真：统一埋点口径 + 每周抽样核验

## 8. 退出标准（可写入简历）
- 连续 2 周主流程成功率达到目标阈值
- 至少 1 次可量化迭代闭环（有前后数据对比）
- 内容导入流程可由 SOP 独立执行
